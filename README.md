# Textify RS

Аналог [Textify](https://ramensoftware.com/textify) на Rust: копирует текст из
диалогов и окон, где его нельзя выделить мышкой.

Разработчик: Харченко Евгений Сергеевич (@domahes).

## Иконка

Рисунок (окно с текстовым курсором) описан в `src/icon_art.rs` и используется в
двух местах: значок в трее/заголовке окна рисуется во время работы, а в exe
встраивается `assets/TextifyRS.ico` (размеры 16, 24, 32, 48, 256). После
изменения рисунка перегенерируйте файл и пересоберите:

```bat
cargo run --bin gen_icon
cargo build --release
```

Встраивание ресурсов (иконка + манифест) выполняется сборочным скриптом без
внешних утилит: на GNU-тулчейне создаётся COFF-объект с секцией `.rsrc`
(`build/coff.rs`, `build/resources.rs`).

Наведите курсор на текст и нажмите **Shift + средняя кнопка мыши**. Появится
окно с этим текстом, а сам текст сразу попадёт в буфер обмена.

Чтобы скопировать не одну строку, а **всё меню целиком**, удерживайте
**Ctrl + Shift** и нажмите среднюю кнопку мыши на открытом меню.

## Как это работает

1. Глобальный хук мыши ловит шорткат и не отдаёт щелчок целевому окну.
2. Текст элемента под курсором берётся из UI Automation. Если MSAA видит более
   вложенный элемент, выбирается он.
3. Если оба способа молчат, текст собирается через `WM_GETTEXT` у самого окна
   и его статических надписей.
4. Результат показывается во всплывающем окне. Оно закрывается, когда теряет
   фокус.

Во всплывающем окне:

| Клавиша | Действие |
| --- | --- |
| Ctrl+C | копировать выделенное или весь текст |
| Ctrl+A | выделить всё |
| Tab / Shift+Tab | перейти к следующему фрагменту |
| F2 | закрепить окно (появится заголовок, окно перестанет закрываться само) |
| Esc | закрыть |

## Режим «всё меню»

Сочетание **Ctrl + Shift + средняя кнопка мыши** (то есть Ctrl+Shift+нажатие
колеса) копирует не одну строку под курсором, а всё содержимое открытого меню.
Щелчок поглощается, поэтому меню остаётся открытым до тех пор, пока его не
закроет появившееся окно результата.

Меню читаются тремя способами, по порядку:

1. для классических меню Win32 (`#32768`) пункты берутся прямо из `HMENU`
   окна меню, вместе с уже открытыми подменю;
2. для современных интерфейсов (Office, Chromium, WinUI) — через UI Automation:
   берётся ближайшее меню или строка меню и все его пункты по порядку;
3. для старых программ — через MSAA (`IAccessible`).

Если курсор наведён не на меню, режим ничего не меняет: выполняется обычный
захват элемента под курсором. В подписи окна результата такой захват помечен
как «Всё меню».

Извлечение выполняется в отдельном потоке, поэтому медленное приложение не
блокирует интерфейс Textify RS. Пока захват выполняется, сохраняется только
последний ожидающий запрос; устаревшие результаты не показываются и не
копируются. Если провайдер доступности завис, последующие запросы могут
ожидать его завершения.

Сочетание Ctrl+Shift+СКМ зарезервировано за этим режимом: даже если в настройках
обычный шорткат задан тем же Ctrl+Shift+средняя кнопка, сработает режим «всё
меню», а обычный захват останется на другом сочетании. Как и обычный шорткат,
это сочетание глобальное; если в какой-то программе оно мешает, добавьте её в
секцию `[exclude]` — там перехват отключается целиком.

Программа живёт в трее. Крестик окна настроек не завершает её, а прячет в
трей; полностью выйти можно только пунктом «Выход» в меню значка. Левый
щелчок по значку открывает настройки, правый — меню. В настройках меняются кнопка мыши, модификаторы, необязательный
клавиатурный шорткат, способ извлечения, автокопирование и запуск вместе с
Windows.

Настройки пишутся в `TextifyRS.ini` рядом с программой (или в
`%APPDATA%\TextifyRS\settings.ini`, если каталог программы недоступен для
записи). Список программ, на которых шорткат не должен срабатывать, задаётся
секцией `[exclude]`:

```ini
[exclude]
1=game.exe
```

## Сборка

Нужен Rust. Проект собирается и на MSVC, и на GNU-тулчейне; линкер MinGW не
требуется — используется `rust-lld` из rustup.

```powershell
cargo build --release
.\target\release\TextifyRS.exe
```

Запуск без окна настроек: `TextifyRS.exe -hidewnd`. Повторный запуск не
создаёт второй экземпляр, а показывает окно настроек уже работающей копии.

Отладочная сборка (`cargo build`) открывает консоль. Из неё можно проверить
извлечение без интерфейса:

```powershell
.\target\debug\TextifyRS.exe --capture 400 300
.\target\debug\TextifyRS.exe --capture --method=msaa
```

`--capture` без координат берёт точку под курсором. `--method` принимает
`auto`, `uia`, `msaa` или `window`. Флаг `--menu` включает режим «всё меню»:

```powershell
.\target\debug\TextifyRS.exe --capture --menu 120 340
```

Тесты запускаются командой `cargo test`. Живая проверка режима «всё меню»
открывает настоящее меню, поэтому по умолчанию она пропускается:

```powershell
cargo test -- --ignored
```
